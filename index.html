Core Concept: One-Time Programmable (OTP) MCUsОсновно понятие: еднократно програмируеми (OTP) микроконтролери

OTP microcontrollers can be programmed only once. If the firmware contains an error, the programmed device cannot be erased and reprogrammed. They are therefore best suited to production after the firmware has been thoroughly tested.OTP микроконтролерите могат да бъдат програмирани само веднъж. Ако във фърмуера има грешка, записаният микроконтролер не може да бъде изтрит и препрограмиран. Затова са подходящи за производство след задълбочено тестване на програмата.

Practical takeaway: OTP devices are inconvenient during development but can be cost-effective in large production runs. Reprogrammable Flash memory is more suitable for prototyping.Практически извод: OTP микроконтролерите са неудобни при разработка, но могат да бъдат икономични при големи производствени серии. Препрограмируемата Flash памет е по-подходяща за прототипиране.

Основни архитектурни елементи
1. Program Bus (14-bit): Fetches instructions directly from FLASH/OTP memory to the CPU.Извлича инструкции директно от FLASH/OTP паметта към CPU.
2. Address Buses (13-bit & 9-bit): Independent address lines for program flash locations and RAM file registers.Независими адресни линии за програмната памет и RAM регистрите.
3. Peripherals & I/O Ports: Integrated ADC, EEPROM, Timers, and PORT A, B, G for external interaction.Интегрирани АЦП, EEPROM, таймери и портове PORT A, B, G.

Program & Data Memory Architecture Архитектура на Програмната Памет и Паметта за Данни

OTP (One-Time Programmable) PROM

OTP program memory can be programmed once and cannot be erased for correction. Some devices use one-time programmable EPROM or other non-volatile technologies; the implementation depends on the chip.OTP програмната памет се записва еднократно и не може да се изтрие за корекция. Някои устройства използват еднократно програмируема EPROM или други енергонезависими технологии според модела.

EPROM (Erasable PROM) UV Erasable

UV-erasable EPROM devices have a quartz window in the package. Exposure to ultraviolet light erases the memory, after which it can be programmed again. Erase time depends on the device and equipment.EPROM с ултравиолетово изтриване има кварцово прозорче в корпуса. След облъчване с ултравиолетова светлина паметта може да бъде програмирана отново. Времето за изтриване зависи от устройството и оборудването.

FLASH Memory Modern Standard

Flash memory can be electrically erased and reprogrammed, often in-circuit using ICSP. It supports many erase/write cycles and is widely used in modern microcontrollers.Flash паметта може да се изтрива и препрограмира електрически, често директно в схемата чрез ICSP. Поддържа множество цикли на изтриване и запис и се използва широко в съвременните микроконтролери.

RAM vs Data EEPROM
  • RAM: Fast, volatile data memory used for temporary variables and registers.RAM: Бърза енергозависима памет за временни променливи и регистри.
  • Data EEPROM: Non-volatile memory that retains settings and calibration values when power is removed.EEPROM за данни: Енергонезависима памет, която запазва настройки и калибровъчни стойности при изключено захранване.

Reset & Control Block (Блок за НУ и Контрол) Блок за НУ и Контрол

PIC microcontrollers include dedicated hardware sub-modules inside the Reset block to guarantee stable operation and prevent runaway code execution:PIC микроконтролерите включват специализирани хардуерни модули в блока за контрол за осигуряване на стабилна работа и предотвратяване на блокиране:

POR (Power-On Reset): Holds the CPU in reset until power supply voltage reaches stable operational thresholds.Задържа CPU в ресет, докато захранващото напрежение достигне стабилно ниво.
BOR (Brown-Out Reset): Triggers a system reset if supply voltage drops temporarily below safe operating voltage.Предизвиква ресет при временно спадане на захранващото напрежение под критичната граница.
WDT (Watchdog Timer): An independent RC oscillator timer. If code gets stuck and fails to clear WDT before timeout, WDT forces CPU reset.Независим таймер. Ако софтуерът блокира и не "храни" кучето навреме, WDT рестартира процесора.
OST (Oscillator Start-up Timer): Delays execution for 1024 crystal oscillator cycles to ensure clock stability after power-up.Закъснява старта с 1024 генераторни импулса за стабилизиране на кристалния резонатор.
PWRT (Power-up Timer): Provides a fixed ~72ms delay on startup allowing power supply to stabilize fully.Осигурява фиксирано закъснение от ~72ms при включване за пълно стабилизиране на захранването.
MCLR (Master Clear Pin): External hardware reset pin (active low). Pulling to GND forces immediate chip reset.Външен извод за хардуерен ресет. Свързването към маса (GND) рестартира чипа.
